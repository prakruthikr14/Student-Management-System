# Student Management System

## About the Project
A console-based Student Management System developed using Core Java. It allows users to manage student records through a menu-driven interface.

## Features
- Add student records
- View all students
- Search students by ID
- Delete student records
- Save and load student data using file handling

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- File Handling

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Compile the Java files:

   `javac Main.java Student.java`

5. Run the program:

   `java Main`

## Learning Outcomes
Practiced Java classes, objects, constructors, collections, loops, conditional statements, and file handling.
